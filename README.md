# Simple ATM Management System 💳

A simple **Non-GUI ATM Management System** developed using **Python**.
This project is designed as a beginner-level Python project to understand functions, dictionaries, user input, conditions, and basic banking operations.

## 🚀 Features

* 👤 Create a new account
* 🔐 User login with PIN
* 💰 Check account balance
* 💸 Withdraw money
* 🔑 Change PIN
* 🔄 Transfer funds
* 💵 Deposit cash
* 🚪 Exit the application

## 🛠️ Technologies Used

* **Python 3**
* Python Dictionaries
* Functions
* Conditional Statements
* Loops
* User Input

## ▶️ How to Run

1. Install **Python 3** on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code or any Python editor.
4. Run:

```bash
python atm.py
```

5. Follow the instructions displayed in the terminal.

## ⚠️ Important Note

This is an **educational/demo project** and is not intended for real banking use.

The current version stores account information in Python dictionaries. Therefore, newly created accounts and updated balances are **not permanently saved** after the program is closed.

For a production-level application, a proper database such as **MySQL** or **SQLite** should be used.
